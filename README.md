# Spotify Clone

A Spotify-inspired music player web project built using HTML, CSS and JavaScript.

## Features

- Spotify-inspired user interface
- Music playlist with multiple songs
- Play and pause functionality
- Previous and next song controls
- Song thumbnails and details
- Responsive layout
- Navigation bar and search section

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Highlights

This project helped me practice building a music player interface, handling audio elements with JavaScript, creating interactive controls, and designing a responsive web layout.
